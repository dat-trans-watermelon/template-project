# Template Project

A minimal starter template for new projects.

## Structure
```
├── src/           # Source code
├── tests/         # Test files
├── docs/          # Documentation
├── .github/
│   └── workflows/ # CI/CD pipelines
├── .gitignore
├── LICENSE
└── README.md
```

## Getting Started

```bash
# Clone
git clone https://github.com/YOUR_USERNAME/template-project.git

# Install deps (if applicable)
# make install / npm install / cargo build / etc.

# Run tests
# make test / npm test / cargo test
```

## CI/CD
GitHub Actions workflow in `.github/workflows/ci.yml` runs on push/PR.
